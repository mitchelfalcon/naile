## 🎮 Ejercicio 1: Par o Impar

Vista del simulador interactivo con código y explicaciones.

```
┌─────────────────────────────────────────────────────────┐
│  ← Volver                                                │
│                                                          │
│  Ejercicio 1: Par o Impar [Estructura Selectiva]        │
│                                                          │
│  ┌──────────────────────┐ ┌──────────────────────┐      │
│  │ ▶️ Simulador         │ │ 💻 Código C++        │      │
│  │                      │ │                      │      │
│  │ ┌──────────────────┐ │ │ [Código] [Explicac.]│      │
│  │ │ > Ingrese número │ │ │                      │      │
│  │ │ [____8____]      │ │ │ #include <iostream> │      │
│  │ │ [Ejecutar ▶]    │ │ │ int main() {        │      │
│  │ │                  │ │ │   int numero;       │      │
│  │ │ Output:          │ │ │   ...               │      │
│  │ │ El número 8      │ │ │ }                   │      │
│  │ │ es par.          │ │ │                      │      │
│  │ └──────────────────┘ │ └──────────────────────┘      │
│  │                      │                      │      │
│  │ 💡 Sugerencia:       │                      │      │
│  │ Prueba con 3, 8...   │                      │      │
│  └──────────────────────┘                      │      │
└─────────────────────────────────────────────────────────┘
```

**Funcionalidades:**
- Campo de entrada para el número
- Botón de ejecución
- Visualización del resultado en tiempo real
- Código C++ completo con comentarios
- Explicaciones de conceptos clave
